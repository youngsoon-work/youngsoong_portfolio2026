Improving the UI of an endpoint protection product

Client
SecureAge Technology
Role
Creative Designer
Year
2022

About the project

CatchPulse, formerly known as SecureAPlus, is an endpoint security solution that provides robust malware protection. The company collaborated with an external UX agency for its relaunch, and I joined the project midway through.

My role

I contributed to the UI improvements for this project. As the designer responsible for the company’s overall visual identity, I provided the agency with comprehensive UI guidelines — including color schemes, fonts, and icon styles — along with sample screens.

Old design

The interface of SecureAPlus was designed a long time ago and had only undergone minor updates since then. A relaunch was planned, taking into account new features and issues with the previous design. Developers, PMs, and an external agency collaborated to design a new layout.

New design

The first draft was created by the UX agency, and I was brought in to review and refine this design. I focused on improving the UI rather than the functional aspects of UX. I created several sample designs and delivered them along with guidelines to the agency, which then used them to design dozens of screens.

Refining the UI

Considering the overall timeline, I aimed to improve the design without making significant changes. First, I focused on enhancing visibility by adjusting the font size and addressing color contrast, in line with WCAG standards. I then established a consistent icon style and applied a new color scheme to align with the company’s overall brand guidelines.
